# Day 1. What Is Python?

## 1. Introduction to Python

Python is a high-level programming language created by Guido van Rossum. Its development began in late 1989, and it was first publicly released in 1991.

- **Interpreter (인터프리터):** A program that executes or helps execute source code.
- **Maintainability (유지 보수성):** How easily software can be modified and maintained.
- **Readability (가독성):** How easily people can understand source code.

### Advantages of Python

- Easy-to-read syntax
- Simple and concise code
- Useful for collaboration and maintenance
- Free and open-source implementations

## 2. What Can Python Be Used For?

| Application | Description |
|---|---|
| System Utilities | Creating tools that help manage and automate computer tasks |
| GUI Programming | Developing applications with graphical interfaces |
| Web Development | Building websites and web applications |
| Numerical Computing | Performing mathematical and scientific calculations |
| Database Programming | Connecting to and working with databases |
| Data Analysis | Processing and analyzing data |
| Internet of Things (IoT) | Controlling devices such as Raspberry Pi |

### Useful Libraries and Tools

- **Tkinter:** A standard Python interface for Tcl/Tk, commonly used to create simple graphical applications.
- **NumPy:** A library for numerical computing.
- **Pandas:** A library for data manipulation and analysis.
- **Raspberry Pi:** A small, general-purpose computer that can be used for electronics and IoT projects.

## 3. Limitations of Python

Python may not be the best choice for every task.

- **Performance-critical applications:** C and C++ may be more suitable when execution speed is critical.
- **Low-level programming:** C and C++ are often preferred for direct hardware access and systems programming.
- **Mobile application development:** Python can be used, but other languages and frameworks are more common in mainstream mobile development.

## 4. Key Takeaways

- Python emphasizes readable and concise syntax.
- Python can be used for web development, automation, data analysis, and IoT.
- Libraries extend Python's capabilities.
- The best programming language depends on the requirements of the project.
